Web & Backend Development

Forex Trading Management System

Hệ thống quản lý giao dịch ngoại hối tập trung vào việc xử lý các lệnh OCO (One-Cancels-the-Other) và tính toán lỗ lãi chưa thực hiện (Unrealized PnL) theo thời gian thực.

Backend được xây dựng để xử lý hàng nghìn request mỗi giây, đảm bảo tính nhất quán của dữ liệu tài chính và cấu hình phiên giao dịch linh hoạt.

Tech Stack: Java Spring Boot MySQL Redis Kafka
Key Features:
  • Real-time PnL Calculation dựa trên luồng dữ liệu thị trường trực tiếp.
  • Hệ thống xử lý lệnh OCO tự động hủy lệnh đối ứng khi một lệnh khớp.
  • Phân quyền quản trị và báo cáo giao dịch chi tiết.
